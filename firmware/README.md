# Прошивка для NodeMCU (ESP8266)

Скетч `LightOnThePalm/LightOnThePalm.ino` управляет адресной лентой WS2812 и общается с приложением по HTTP. Текущая версия: **018** (история версий — в комментарии в начале файла).

Папка скетча называется так же, как файл, — этого требует Arduino IDE.

## Что нужно
- Плата NodeMCU (ESP8266), в Arduino IDE — пакет плат ESP8266.
- Библиотека **FastLED** (менеджер библиотек Arduino IDE).
- Лента WS2812, сигнальный провод на пин, заданный константой `LED_PIN` в скетче.

## Прошивка
1. Откройте `LightOnThePalm/LightOnThePalm.ino` в Arduino IDE.
2. Выберите плату NodeMCU 1.0 (ESP-12E Module) и порт.
3. Загрузите скетч.

Сообщение компилятора FastLED про отсутствие аппаратных SPI-пинов (`No hardware SPI pins defined`) — не ошибка.

## Как ведёт себя лента
- Бегущий огонёк: красный — сети нет (первое включение или домашняя сеть недоступна), бирюзовый — лента в домашней сети, фиолетовый — лента в своей сети NodeMCU (пароль 12345678, адрес 192.168.1.1).
- Подробное описание — в разделе «Справка» приложения.

При изменении приложения, которое требует новой версии прошивки, номер версии в начале скетча увеличивайте.
